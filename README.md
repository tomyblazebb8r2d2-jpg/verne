# Verne Study Club · sitio web

Sitio estático (HTML + CSS + un poco de JS, sin compilación) publicado con GitHub Pages.

- `index.html`, `estilos.css`, `principal.js`: la página.
- `diagnostico.html`: examen diagnóstico de álgebra (envía el resultado por WhatsApp).
- `assets/`: logo original vectorizado (animado y horizontal), avatar, favicon, imagen para redes (`og.png`).
- `fonts/`: Nunito (licencia SIL OFL, ver `fonts/OFL.txt`).
- `construir_logo.py`: regenera los SVG del logo desde `marca/verne/original` del motor de videos.

Para cambiar precios, fechas o el teléfono, edita `index.html` (busca el texto) y vuelve a publicar.
